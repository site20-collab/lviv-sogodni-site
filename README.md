# Львів Сьогодні

Редакційне онлайн-медіа: публічний сайт, панель редакції, ролі, матеріали, медіа, коментарі, SEO, RSS, карта сайту і власна статистика.

Середовище збірки — TanStack Start, PostgreSQL (у прев’ю вбудована база, у публікації — виділена) і Better Auth. Prisma й окремий S3 тут не використовуються: схема живе в `migrations/`, завантажені зображення зберігаються в базі й віддаються за адресою `/api/media/...`.

## Локально

```bash
npm install
npm run dev
npm run build
npm test
```

Міграції застосовуються під час збірки (`npm run db:migrate`) і автоматично в прев’ю. Окремий `.env` не потрібен у цьому прев’ю: рядок бази і секрети автентифікації підставляються під час публікації кнопкою Publish.

## Свій GitHub і свій хостинг

GitHub зберігає код, але не запускає цей сайт. Це не статичні сторінки: потрібні Node.js 22 і PostgreSQL. Найпростіше — репозиторій на GitHub і публікація на [Vercel](https://vercel.com), база на [Neon](https://neon.tech).

1. Створіть порожній репозиторій на GitHub і завантажте вміст архіву (папку `node_modules` не додавайте).
2. У Neon створіть базу PostgreSQL і скопіюйте рядок підключення.
3. У Vercel: Add New → Project → Import цього репозиторію. Build command: `npm run build`. Node.js: 22.
4. Environment Variables:

   | Змінна | Значення |
   |---|---|
   | `DATABASE_URL` | рядок підключення з Neon |
   | `BETTER_AUTH_SECRET` | довгий випадковий рядок (від 32 символів) |
   | `BETTER_AUTH_URL` | публічна адреса сайту, наприклад `https://ваш-проєкт.vercel.app` |

5. Deploy. Після першого відкриття сайту з’явиться редакція: `/admin/login`, пошта `redaktor@lviv-sogodni.media`, пароль `Lviv-Demo-2026!`. Пароль одразу змініть.
6. Заплановані матеріали: у налаштуваннях редакції є секрет. Раз на кілька хвилин надсилайте `POST` на `https://ваш-сайт/api/cron/publish-scheduled` із заголовком `x-cron-secret`. Якщо крон не налаштований, прострочена новина все одно вийде, коли хтось відкриє сайт.

Зображення лежать у базі, окреме сховище файлів не потрібне.
